# Context: site pessoal de Mateus Silva Oliveira

## Purpose
Site pessoal que apresenta quem é o autor, os artigos que ele escreve e os projetos que ele constrói.

## Terms
| Term | Definition |
|------|------------|
| Abertura | Primeira tela da home: o nome do autor, os cards de projeto em volta dele e um pedaço da seção Sobre aparecendo embaixo. |
| Card de projeto | Representação curta de um projeto na abertura: nome e uma linha de descrição. Clicar abre o projeto na seção Projetos. |
| Projeto fixo (`pinned`) | Projeto que fica sempre na fileira de cima da abertura e nunca sai dela. No máximo 3; se houver mais marcados, valem os 3 primeiros pela ordem. |
| Rodízio | Os lugares da abertura que não são fixos. Por eles passam, um de cada vez, todos os projetos que não são fixos. |
| Seção Projetos | Lista com os nomes de todos os projetos e, ao lado, o projeto escolhido em detalhe: descrição, temas, link e, quando houver, o fluxo das fontes que o alimentam. |
| Projeto em destaque (`featured`) | Projeto que a seção Projetos mostra aberto quando a página carrega. Não tem relação com a abertura. |
| Sobre | Seção logo após a abertura com o resumo do autor: bio, temas, "Agora" e "Consumindo". |

## Relationships
Um projeto pode ser fixo, em destaque, os dois ou nenhum. Ser fixo decide só onde ele aparece na abertura; estar em destaque decide só qual projeto a seção Projetos mostra primeiro.
